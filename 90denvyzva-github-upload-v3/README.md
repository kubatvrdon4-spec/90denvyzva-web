# Keller — weby pro trenéry

Nová prodejní verze webu 90denvyzva.cz. Původní nabídka 90denní výzvy byla nahrazena čistou prezentací tvorby webů pro fitness trenéry a sportovní projekty.

## Spuštění

```bash
npm install
npm run dev
```

Produkční sestavení:

```bash
npm run build
```

## Nasazení na Vercel

Projekt je připravený pro běžný postup GitHub → Vercel. Vercel automaticky rozpozná Vite a použije:

- Build command: `npm run build`
- Output directory: `dist`
